# KubeTrim Hub Design Philosophy & UI Architecture (October 2026)

KubeTrim Hub enforces an Avant-Garde **Tactile Editorial & Precision UI** standard (inspired by Linear, Teenage Engineering, and Stripe Press) to present high-density Kubernetes FinOps telemetry, `T0 -> T1` attribution, and 1-Click GitOps remediation without generic AI/SaaS visual clichés.

## 1. Strict Negative Constraints (Anti-AI Slop Rules)

1. **No generic SaaS gradients:** Strictly prohibit indigo-to-purple, blue-to-cyan, or glowing neon background blobs.
2. **No symmetrical 3-column icon cards:** Never render 3 equal cards with a centered icon inside a colored circle.
3. **No generic centered Hero:** Never use a centered pill badge above an H1 with two rounded-full buttons.
4. **No blurry Tailwind drop shadows:** Prohibit `shadow-md`, `shadow-lg`, and `shadow-xl` on cards.
5. **No pure `#FFFFFF` or `#000000` backgrounds** and no default `blue-500` / `indigo-600` accents.
6. **No generic marketing copy:** Use domain-accurate Kubernetes FinOps microcopy (`p95 * 1.25 CPU headroom`, `Guaranteed QoS oom_score_adj=-997`, `HPA anti-flapping guard`, `SHA-256 ConfigHash`).

## 2. Typography, Materiality & Color Systems

* **Typography Trio:**
  * **Editorial Serif:** `Instrument Serif` or `Newsreader` (fluid `clamp()`, `-0.03em` tracking).
  * **Precision UI Sans:** `Plus Jakarta Sans` or `Inter`.
  * **Technical Monospace:** `JetBrains Mono` for `01 //` indices, PromQL formulas, SHA-256 hashes, and USD metrics.
* **Spatial Architecture:** Asymmetric Swiss blueprint grid with exposed `1px solid` structural hairlines, fixed SVG `fractalNoise` (`opacity: 0.035`), and `inset 0 1px 0 0 rgba(255,255,255,0.1)` top-edge highlights.
* **Palettes:**
  * **Obsidian Industrial Dark:** `#0B0C0E` canvas, `#121316` surface, `#22242A` hairlines, `#ECECEE` ink, `#F59E0B` (raw amber) or `#D4FF00` (acid lime) accent.
  * **Warm Analog Light:** `#F6F5F0` paper canvas, `#141413` charcoal ink, `#E6E4DD` stone borders, `#FF4F00` (international orange) or `#1B4332` (forest green) accent.
